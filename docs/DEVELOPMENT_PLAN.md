# 开发计划

## 阶段 0 — V1.0 MVP（已完成）
- [x] Expo SDK 58 + TypeScript + Expo Router 项目
- [x] 首页、学科页、课程播放器、家长中心
- [x] 三科各一节完整样板课
- [x] 4 种可复用练习组件 + 4 种课程环节（演示、拖篮子、合起来、开放题、听读卡片、跟读、对话、绘本）
- [x] 本地进度、星星、错题、继续学习
- [x] 拼音词库自动核对、单元/组件测试、网页端到端验收
- [x] EAS 构建配置（APK）

验收：见 docs/TEST_REPORT.md。

## 阶段 1 — 真机验证与打磨（下一步，约 1 周）
- [ ] 用户在 2–3 台常见安卓手机（含平板）上安装 APK，记录发音、拖动、布局问题
- [ ] 若系统语音质量不理想：为样板课全部词句录制真人音频（或用合规 TTS 服务预生成），`Speakable` 增加音频字段
- [ ] 应用图标、启动图换成“星星宝”原创形象
- [ ] 孩子真实试用 2–3 次，观察能否独立完成（不需要大人讲解）
验收：真机上 10 项验收全部通过；孩子独立完成一节课。

## 阶段 2 — 课程扩充（约 2–4 周）
- [ ] 数学：认识 1–10、比大小（>、<、=）、10 以内加减法、生活应用题（每个主题 1–2 节）
- [ ] 语文：拼音单韵母、声母启蒙，识字扩充，词语与句子
- [ ] 英语：颜色、动物、身体、家庭等主题，首字母扩展到 26 个
- [ ] 每节课内容由家长/老师审核，标注来源；若对应具体教材，需人工核实后标为 verified-textbook
验收：每节课通过内容测试；家长审核记录。

## 阶段 3 — 智能复习（约 2 周）
- [ ] 基于 `results` / `mistakes` 的知识点按间隔复习（错题优先）
- [ ] 首页“今日复习”任务
验收：错题在 1、3、7 天后出现在复习中，答对后间隔延长。

## 阶段 4 — 口语能力（需要原生模块与云服务）
- [ ] expo-audio 录音 + 回放对比（不需要云服务）
- [ ] 接入语音评测服务做发音评分（需选型、账号、隐私合规审核）
- [ ] AI 对话练习（需选型与儿童内容安全策略）
验收：真实识别结果，不允许随机分数。

## 风险
| 风险 | 应对 |
|---|---|
| 国产安卓手机缺少 TTS 语音包 | 阶段 1 改为内置真人音频 |
| 儿童隐私合规（《儿童个人信息网络保护规定》） | V1.0 不收集任何个人信息、不联网；上线前准备隐私政策与监护人同意流程 |
| 教材对应准确性 | 原创为主，对应教材必须人工核实 |
