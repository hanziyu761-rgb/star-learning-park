# 视觉与交互规范（V5.0）

参照苹果 Human Interface Guidelines：干净、柔和、留白多；精致、童趣但不幼稚。

## 写页面时的规则
1. 颜色只从 `src/theme.ts` 取：`colors.xxx`、`subjectTheme[学科]`。不写 `'#fff'` 之类的固定颜色（插画、游戏场景、单词卡纸片除外）。
2. 样式表写成 `const styles = themed(() => StyleSheet.create({ ... }))`，切换深色时自动换成深色样式。
3. 写文字样式一定写 `color`（React Native 默认黑字，在深色模式下看不见）。
4. 按钮用 `Pressable`（从 `@/components/Tappable` 引入，全 APP 已统一），自带弹簧手感；遮罩、整页面板传 `scaleTo={1}`。
5. 彩色按钮上的文字用 `colors.onAccent`（浅色模式白字、深色模式黑字）。
6. 可点击区域至少 44×44，孩子用的按钮 64 以上（`MIN_TOUCH`）。

## 配色（莫兰迪色）
| 用途 | 浅色模式 | 深色模式 |
|---|---|---|
| 页面底色 `bg` | 乳白 #F5F3EF | 纯黑 #000000（OLED 省电） |
| 卡片 `card` / 分组 `cardAlt` | #FFFFFF / #F0EDE8 | #1C1C1E / #2C2C2E |
| 正文 `text` / 次要 `textSoft` | #1D1D1F / #6B6B70 | #F5F5F7 / #A1A1A6 |
| 数学 / 语文 / 英语 | 雾蓝 #4A76A0 / 豆沙红 #AD5A56 / 灰绿 #4E7D5F | 提亮的同色系 |
| 主色 `primary` | 陶土 #A65F47 | #E8A58C |
| 答对 / 答错 | 灰绿 / 豆沙红（带浅底） | 提亮 |

自动检查（`__tests__/design.test.tsx`）：正文对比度 ≥ 7:1，彩色文字在卡片上 ≥ 4.5:1，彩色按钮上的文字 ≥ 4.5:1；主要颜色彩度 ≤ 0.4（不用霓虹色）。

## 字体与留白
- 系统字体：苹果手机是 San Francisco / 苹方，安卓是系统中文字体。San Francisco 按苹果授权不能打包进安卓 APP。
- 字号层级 `type`：largeTitle 34、title1 28、title2 22、title3 20、headline 17（半粗）、body 17、subhead 15、footnote 13、caption 12。标题粗体 700，正文常规 400，不用 800/900 的超粗字。
- 页面左右留白 20，卡片之间 24，卡片内边距 16～20；平板内容最宽 760、居中。

## 形状与材质
- 圆角 `radius`：小 16、中 24、大 32、特大 40；卡片用 24 以上，苹果式连续圆角（`borderCurve: 'continuous'`）。
- 阴影 `shadow`：浅色模式两层淡暖灰投影；深色模式不用阴影，改一圈很淡的亮边。
- 毛玻璃 `Glass`：顶部导航栏（内容从下面滑过）。苹果手机、网页实时模糊；安卓用半透明底（安卓实时模糊在旧手机上耗电、卡顿）。

## 动效（react-native-reanimated 弹簧）
- 按下缩到 0.95，松开轻微回弹（`spring.press` / `spring.release`）。
- 答对：选项弹一下（`pop`）；答错：左右轻摇（`shake`）；反馈条弹簧浮上来。
- 首页各块依次浮上来；分段选择的滑块弹簧滑动。
- 页面切换：安卓 `ios_from_right`（苹果式推入推出），苹果手机系统默认推入，单文件版弹簧推入、返回从左推回。
- 系统打开“减弱动态效果”时，按钮不缩放、不弹。

## 深色模式
家长中心 → 外观：跟随手机 / 浅色 / 深色（`settings.appearance`，旧记录按跟随手机）。

## 检查
- 网页巡检：逐页截图，并找出文字和底色对比度不足 3:1 的地方；全部端到端脚本另外在深色模式下跑一遍，每次点击后检查。
- 未验证：真机上的毛玻璃效果、弹簧手感、深色模式下的状态栏和系统导航栏。
