# 星星学习乐园 — 产品需求文档（V1.0）

## 1. 产品定位
中国小学生智能互动学习 APP（英文标识 Star Learning Park）。第一期面向小学一年级、6–7 岁儿童，优先 Android 手机和平板，架构兼容 iOS。
目标：孩子能独立操作，每天 15–20 分钟，通过演示、听读、拖动、游戏和练习完成学习。

## 2. 核心原则
- 儿童独立操作：大按钮（最小 64dp）、少文字、语音引导、中文带拼音。
- 先理解、再练习、再迁移：每节课按“演示 → 动手 → 练习 → 开放/迁移 → 反馈”组织。
- 准确性：拼音逐字人工填写并经词库自动核对；课程标注内容来源。
- 不做假功能、不造假数据。

## 3. 用户与场景
| 角色 | 场景 |
|---|---|
| 孩子（6–7 岁） | 放学后自己打开 APP，点学科、跟着语音完成一节课，得到星星 |
| 家长 | 通过算术验证进入家长中心，查看完成情况、正确率、错题和薄弱点 |

## 4. V1.0 功能范围
| 模块 | V1.0 实现 |
|---|---|
| 儿童首页 | 吉祥物问候（可朗读）、星星总数、继续上次学习、三科入口（点按朗读学科名）、今日任务（每科一节，按当天真实完成情况打勾）、学习进度、家长入口 |
| 数学课 | 《合起来是几》：数数动画、拖苹果进篮子、两盘合起来（加法含义）、数一数、比多少、数字与数量拖动配对、1+4、判断 2+2=5、1–5 排序、开放题（用苹果和梨凑 5，多种答案） |
| 语文课 | 《日月水火山》：点字听读（带拼音和组词）、字图拖动配对、听音识字×2（隐藏拼音）、看图认字、词语卡片、组词选择、看图判断句子×2 |
| 英语课 | 《Fruits》：听读卡片、听音选图×2、跟读（自评，不打分）、首字母卡片、字母-水果拖动配对、情境对话、听句选图、5 页互动绘本（点单词发音）、看图判断 |
| 练习系统 | 选择题（图片/数字/文字/听音）、正误判断、拖动配对（也支持“先点后点”）、点击排序；统一的答对/答错反馈、重试、提示、结果记录 |
| 学习进度 | 本地保存：完成课程、每题第一次是否答对、尝试次数、错题（再次一次答对自动移出）、学习次数、最近学习时间、累计星星、未完成课程的步骤位置 |
| 奖励 | 按第一次作答正确率给 1–3 颗星（≥90% 3 颗，≥60% 2 颗，完成 1 颗） |
| 家长中心 | 乘法验证防误入；总览、分学科统计、最近完成课程、薄弱知识点、错题列表、清除记录（二次确认）；空状态说明 |

## 5. 明确不在 V1.0 的功能（标注为后续版本）
- 录音跟读、发音评分、语音识别、AI 口语对话：需要原生录音与语音识别服务，V1.0 跟读环节仅“听示范 → 自己说 → 自己点‘I said it!’”，界面上明确写明“录音跟读和发音评分将在后续版本提供”。
- 真人录音音频：V1.0 使用手机系统语音合成。
- 原创插画：V1.0 配图使用系统表情符号和代码绘制的原创吉祥物“星星宝”。
- 账号、云同步、多孩子档案、智能复习推荐（数据模型已预留：按知识点记录正误与错题）。

## 6. 课程内容规范
- 数学、语文参考《义务教育课程标准》一年级知识范围，题目原创。
- 每节课在数据中标注 `source`（original / verified-textbook / unverified）和 `sourceNote`。V1.0 三节课均为“原创”，语文识字范围参考一年级上册常用字，具体教材版本与课次未核实。
- 英语：大量听力输入、图像与声音对应、首字母启蒙、日常场景，积极鼓励；指令用英文，可选中文小提示。
