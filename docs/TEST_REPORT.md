## 4. 未能验证的项目（需要在真机上确认）
| 项目 | 原因 |
|---|---|
| 安卓真机上的实际发音效果 | 云端没有安卓设备；网页测试只能确认“调用了朗读、语言正确”，听不到声音。国产手机若未安装中文/英文语音包可能无声或声音生硬 |
| 安卓真机上的手指拖动手感 | 网页用鼠标模拟；真机使用原生手势系统，代码相同但需实测 |
| 安卓上关闭 APP 再打开的数据保留 | 网页版用浏览器存储验证；安卓使用原生 AsyncStorage，逻辑由单元测试覆盖，仍建议真机确认 |
| 震动反馈 | 网页不支持 |
| APK 构建 | 需要你的 Expo 账号登录后在云端构建 |
