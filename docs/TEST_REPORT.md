## 4. 未能验证的项目（需要在真机上确认）
| 项目 | 原因 |
|---|---|
| 安卓真机上的实际发音效果 | 云端没有安卓设备；网页测试只能确认“调用了朗读、语言正确”，听不到声音。国产手机若未安装中文/英文语音包可能无声或声音生硬 |

| APK 构建 | 需要你的 Expo 账号登录后在云端构建 |
