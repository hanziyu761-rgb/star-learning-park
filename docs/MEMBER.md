# 会员（V5.3）使用说明

会员价 **9.9 元 / 月**。不需要营业执照、商户号：家长微信转账给你，你用“会员开通工具”生成开通码发给家长。

## 规则
- 新安装（或第一次升级到 5.3 的手机）**免费试用 7 天**，所有功能都能用。
- 试用结束、没有开通会员：首页、学科页、家长中心、教材资源库、知识地图照常打开；**每天可以免费做 1 套“今日一练”**（同一套当天可以再打开）；其它功能（课程、单元练习、游戏、每日挑战、单词卡、试卷、AI 老师、拍错题等）会弹出“请爸爸妈妈来看看”。
- 会员到期日当天仍可用，第二天自动停用。
- 开通后每 7 天至少联网一次（打开 APP 时自动核对），这样你在服务器上“关闭”才能生效。超过 7 天没联网会提示联网核对。
- 学习记录不会因为开通、到期、关闭而丢失。

## 你手里的东西
| 文件 | 用途 | 注意 |
|---|---|---|
| `linheng-member.admin.html`（会员开通工具） | 生成开通码、记录谁开通到哪天、生成关闭名单 | **里面有管理员私钥，只给自己用**；电脑和手机各存一份备份。丢了就不能再开通（只能换新钥匙、重新打包 APP，已开通的码会全部失效） |
| `ai-worker-v5.3.zip` | 阿里云函数计算的新版服务代码（加了“关闭名单”核对） | 上传方法见下面“第一次准备” |

## 第一次准备（只做一次）
1. **保存开通工具**：把 `linheng-member.admin.html` 存到电脑上（再发一份到自己手机的文件里备份）。用电脑浏览器（Chrome、Edge）或手机浏览器打开即可，不需要联网。微信里直接点开可能打不开，请选“用其他应用打开 → 浏览器”。
2. **更新服务器代码**：阿里云函数计算控制台 → 函数 `star-ai-teacher` → “代码” → 上传 `ai-worker-v5.3.zip` → “部署”。启动命令、端口、原来的环境变量都不变。
3. **检查**：浏览器打开 `你的服务地址/api/member/check?d=00000000`，看到 `"ok":true,"revoked":false` 就好了。

## 开通一位家长
1. 家长打开 APP → 家长中心（做一道乘法题验证）→ 最上面“会员” → 点“复制”设备号，微信发给你，并转账。
2. 你打开开通工具：填设备号、备注（例如“张三 · 二年级”）、选时长 → 点“生成开通码” → 点“复制”，粘贴到微信发给家长。
3. 家长在“会员”里点“粘贴” → “开通”，显示“开通成功！会员有效期到 ……”。

续费：在开通工具的记录里点“续费”（或再输入同一个设备号）→ 生成 → 发给家长。新的到期日从原来的到期日往后延。
自己家的孩子：时长选“长期（10 年）”。

开通码只能在那一台手机上用；家长换手机、卸载重装后设备号会变，需要按新设备号重新开通（学习记录在旧手机上，不会自动搬过去）。

## 提前关闭某台手机
1. 开通工具的记录里点那台手机的“关闭”。
2. 复制“关闭名单”那一行（例如 `7K2M-9QXA,3H8P-2WZD`）。
3. 阿里云函数计算 → 函数 `star-ai-teacher` → “配置” → “环境变量” → 添加或修改 `MEMBER_REVOKED`，值就是这一行 → 保存。
4. 那台手机下次联网打开 APP 时停用；如果一直不联网，最多 7 天后也会停用。

恢复：在记录里点“恢复”，再把新的关闭名单保存到 `MEMBER_REVOKED`（名单为空时可以删掉这个环境变量）。

## 安全说明（实话）
- 开通码用数字签名（Ed25519），没有你的开通工具造不出能用的码；码和设备号绑定，转给别人也用不了。
- 能修改安装包的人理论上可以绕过检查（所有不联网的收费方式都有这个问题）；面向熟人家长时这种风险很小。以后上架应用商店、用户多了，可以改成 APP 内微信 / 支付宝付款（需要营业执照和商户号）。
- 正式公开收费前，建议了解 APP 备案、教育类 APP 备案等要求（以当地主管部门的说法为准）。
