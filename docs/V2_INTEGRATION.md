## 1. 三个项目的真实情况

### A. 星星学习乐园（主体）
- Expo SDK 58 + React Native + TypeScript，Expo Router；另有单文件 HTML 版。
- 3 节精做样板课（数学/语文/英语，共 29 个环节），4 种练习组件，拖动、上注音、系统语音。
- 本地进度：完成、第一次正确率、错题、时长、星星、继续学习；家长中心。
- 未实现：间隔复习、个性化推荐、AI、真人音频、课程数量少。

### B. ChinaStudyFree（聪聪学堂）
- **定位**：小学到大学的全科刷题学习平台。Next.js 15 静态网站，用 Capacitor 包成安卓、Tauri 包成桌面版；Express 后端负责 AI 和语音。
- **一年级相关数据（实测统计）**：
  - 语文 16 个单元 368 题，数学 33 个单元 460 题。英语没有真正的一年级内容：文件名带“一年级”的其实是“一年级起点”教材的三年级。
  - 题型包括判断、选择、填空、计算、连线、排序；每单元另有知识点讲解。
- **题库质量（抽查）**：题目全部为 AI 生成，上游 README 也写明“仍需教师复核”。抽查发现：
  - 超纲：分针走一圈（二年级内容）、乘法（“3 组一共几人”）。
  - 不适合 6 岁儿童：“鱼全死后捞出来”。
  - 答案含糊：“左手拿着什么 → 另一件物体”。
  - 纯文字、没有拼音，一年级孩子读不了；还含 LaTeX 公式（`$0 + 5 = ?$`）。
  - 试卷形式（每单元 40 分钟、百分制），不是互动课。
- **可复用代码**：
  - `packages/core/src/srs.ts`：Leitner 三盒间隔复习，纯 TypeScript，零依赖。
  - `apps/server`：Express AI 后端，接口有出题 / 讲解 / 故事 / 语音；使用 OpenAI 兼容接口，可以接 DeepSeek、通义千问；未配置密钥时返回 501，前端能优雅降级。
  - 成就、商店、联赛等游戏化逻辑。
- **不能直接用**：
  - Next.js 网页组件不能在 React Native 里使用。
  - 免费语音兜底方案 EdgeTTS 是逆向调用微软服务，README 也写了“仅供学习交流”，商用有合规风险。
  - 安卓签名用的是仓库里的演示密钥。

### C. EduAgent
- **定位**：面向大学生和成人的“上传课件 → AI 生成测验、闪卡、思维导图、学习计划”平台。
  - 后端：Python FastAPI + LangGraph + PostgreSQL/pgvector。
  - 前端：React 网页。
- **AI 能力（实测代码）**：
  - 基于文档的检索问答（RAG）。
  - 出题、闪卡、笔记、思维导图、知识点图谱等智能体。
  - 学习计划 `study_plans.py`：统计每个主题的正确率，低于 70% 判为薄弱点，再连同可用的练习资源交给大模型，生成计划。
  - 用量限制：每天聊天、出题次数上限。
- **硬依赖**：
  - 大模型、文档识别：Azure OpenAI（代码里写死 `AzureChatOpenAI` 和 Azure AD 认证）、Azure Content Understanding。
  - 存储与部署：Azure Blob、Key Vault、Container Apps。
  - 登录：Supabase。
  - 部署需要 Terraform、Docker、Postgres。
- **与本项目的差距**：
  - 没有儿童模式、内容安全过滤、家长控制，也没有中文小学课程。
  - 全部能力依赖“用户先上传文档”。
  - 国内使用 Azure OpenAI 需要企业资质。

## 2. 功能整合对照表

| 功能 | 来源 | 结论 | 说明 |
|---|---|---|---|
| 错题间隔复习（1/3/7 天） | B `srs.ts` | **需要适配**（本次已做） | 算法移植为纯函数，并接入现有错题记录 |
| 薄弱知识点 → 学习计划 | C `study_plans.py` | **需要适配**（本次已做规则版） | 保留“正确率 <70% 为薄弱”规则；先用确定性规则推荐课程和复习，以后接 AI 生成说明 |
| 一年级知识点大纲（单元结构） | B `output/*/outlines` | 需要适配 | 作为扩课的知识点参考目录，课程仍按本项目标准精做 |
| 一年级题库（语文 368、数学 460） | B | **暂不建议直接导入** | 质量问题见上；只能经过筛选、改写、加拼音、人工审核后少量引入，见第 4 节 |
| 教材目录（ChinaTextbook 1886 本） | B | 暂不建议 | 面向高年级与家长，链接到 GitHub PDF，不适合一年级孩子 |
| AI 讲解 / 出题 / 故事接口 | B `apps/server` | 需要适配 | 复用 OpenAI 兼容调用方式；需增加儿童安全提示词、输出过滤、频率限制，不收集个人信息 |
| AI 互动老师 / 数学辅导 / 英语陪练 | 三个项目都没有 | **需要重新开发** | 引导式提示（先给思路不给答案）；需要服务端和大模型密钥 |
| 发音评测 | 三个项目都没有 | 需要重新开发 | 需要录音模块和语音评测云服务；B 的 `useRecorder` 只录音、不评分 |
| 预生成语音（真人感音质） | B 的思路 | 需要适配 | 用合规的付费 TTS 服务（如通义）离线生成本项目的音频；不使用 EdgeTTS |
| 游戏化（商店、联赛、宝箱） | B | 暂不建议 | 一年级孩子操作复杂，与“简单”原则冲突；保留星星奖励 |
| 文档上传 RAG、思维导图、闪卡 | C | 暂不建议 | 面向成人，依赖 Azure |
| Supabase 登录、云同步 | C | 暂不建议 | 儿童账号涉及个人信息合规；V2 保持本地优先 |

## 3. 统一架构

```
┌──────────────── 星星学习乐园 APP（Expo RN，唯一前端）────────────────┐
│ 首页 · 学科 · 课程播放器 · 今日复习(新) · 家长中心(含学习建议)        │
│ src/content 课程数据 ─ src/exercises 练习组件 ─ src/progress 学习记录 │
│ src/progress/srs.ts  ← 移植自 ChinaStudyFree（MIT）                   │
│ src/progress/plan.ts ← 规则来自 EduAgent 学习计划（MIT）              │
│ src/ai/（阶段 C）客户端：只调用自家服务端，无密钥；不可用时隐藏/提示  │
└──────────────────────────────┬────────────────────────────────────────┘
                               │ HTTPS（只传题目和知识点，不传孩子身份信息）
                ┌──────────────▼──────────────┐
                │ 星星 AI 服务（阶段 C，Node） │  参考 ChinaStudyFree apps/server
                │ /api/tutor /api/hint /health │  + 儿童安全提示词 + 输出过滤 + 限流
                │ 大模型：OpenAI 兼容接口      │  （DeepSeek / 通义千问，密钥只在服务端）
                └─────────────────────────────┘
```

为什么不合并成一个大仓库：
- B 和 C 的前端分别是 Next.js 和 React 网页，后端分别是 Express 和 FastAPI。整体搬进来，APP 体积、依赖冲突和维护成本都会大增，但对一年级孩子没有对应收益。
- 所以只移植能独立运行的业务逻辑和数据，界面统一由本项目实现。

## 4. 题库引入方案（待你确认）
1. 写导入脚本，读取 B 的一年级数学和语文题，只保留选择题和判断题。
2. 自动筛掉以下题目：
   - 含 LaTeX 的
   - 题干超过 30 字的
   - 含超纲关键词的（乘、除、分针等）
   - 答案不在选项里的
3. 自动校验算术题答案，自动加拼音（多音字列入人工核对清单）。
4. 所有题目标记为 `unverified`，进入“待审核”清单。家长或老师审核后才对孩子开放；审核前不显示。
5. 每道题都配朗读按钮。
