- 沪教版：项目中没有任何数据或功能（仅 docs/KNOWLEDGE_GRAPH.md 规划提到）。
- 原创：知识图谱（每个题库单元一个知识点）、互动课程、口算 / 每日挑战生成器、错题本、复习、AI 老师。
- 题库为 AI 生成、自动质检、未逐题人工审核；没有一册的目录记录过核实来源和日期，所以新底座中全部标“待核实”。

## 数据结构（src/textbooks/types.ts）
Edition（版本）→ Volume（某年级某册，含修订版次）→ Unit（单元）→ LessonEntry（课时）→ 知识点（引用知识图谱 id）→ 例题 / 练习（引用题目 id）

- 每层全局唯一 id：`chinese.tongbian.2024.g4a` / `.u1` / `.u1.l3`
- 来源类别：**A verified** 已核实（必须有官方来源和核对日期）/ **B original** 按课程标准原创 / **C pending** 待核实（二手资料、开源题库）
- 现有数据通过 `adapters.ts` 接入，题库、课程、学习记录不改格式；学习记录仍按原课程 id、题目 id 保存

## 校验（registry.ts `validateAll`）
必填字段；学科与版本一致；年级 1～6、册次上 / 下；编号唯一且层级正确；顺序号递增；“已核实”必须有官方来源；写了现行 / 历史状态必须有来源；同一版本同一修订版同一册不能登记两次；版本名称与别名查重（如“部编版”只能属于统编版）。

## 导入
1. 复制 `docs/textbooks/TEMPLATE.json`（格式示例，不是真实目录）改写
2. 检查：`TEXTBOOK_JSON=文件.json DRY_RUN=1 npx jest --testMatch '<rootDir>/tools/textbooks/*.review.ts'`
3. 去掉 `DRY_RUN=1` 写入 `src/textbooks/data/imported/`，清单自动更新
4. 运行全部检查

## 核实规则
- 只录单元名和课题名，不录课文正文、插图、习题、教参
- 官方来源：国家中小学智慧教育平台电子课本目录页、出版社官网、教育部门文件
- 二手来源（报道、教辅网站）只能作参考，算“待核实”；实际发现同一册两家网站目录不一致（四年级上册《女娲补天》）
