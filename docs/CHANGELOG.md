# 更新记录

## V2.1.0-alpha.1 — 2026-11-04（分支 feature/v2-integration）
图形类数学互动课程（一年级，本项目原创，**待教师审核**），详见 docs/KNOWLEDGE_GRAPH.md 第 6 节。
- 新增：数学乐园「图形乐园」——位置与方向、认识图形、认识积木、认钟表、分一分、找规律，共 73 道原创题
- 新增：7 种互动题型：拖到方格、地图点选、点出所有图形、拖进分类篮、旋转对影子、拨钟（拖分针/时针，时针跟着分针走）、拖图案填规律；均支持“先点再点”替代拖动
- 新增：代码绘制的图形与钟面（react-native-svg），选择题、判断题也可显示图形或钟面
- 接入：6 个知识点开放练习（使用已有编号），作答记录进入掌握度、复习本、找原因诊断（诊断题也可以是拨钟等互动题）和推荐
- 变更：认识整时 ← 认识 11～20 改为必需先修；每轮图形练习 6 题
- 测试：新增 Jest 18 项（共 99 项），新增端到端 `tools/e2e/graphics.py` 21 项
