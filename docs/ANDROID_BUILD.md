# 安卓安装包（APK）打包与真机测试

> 适用版本：V2.4。打包配置 `eas.json` 已准备好（`preview` = 可直接安装的 APK，`production` = 上架用的 AAB）。
> 开发环境（云端工作区）访问不到 Google 的安卓 SDK 下载源，所以安装包需要用下面两种方法之一生成。

## 方法一：Expo 云打包（推荐，不用装安卓开发工具）

需要：一台能上网的电脑（Windows / Mac 都可以），一个免费的 Expo 账号。

1. 打开 https://expo.dev 注册账号（邮箱即可）。
2. 电脑上安装 Node.js 20 或更新版本（https://nodejs.org ，选 LTS）。
3. 解压 `star-learning-park-v2.4-source.zip`，在解压出的文件夹里打开命令行窗口，依次输入：
   ```bash
   npm install
   npx eas-cli login          # 输入你的 Expo 账号和密码（只在你自己的电脑上输入）
   npx eas-cli build -p android --profile preview
   ```
   第一次会询问是否创建项目、是否生成签名密钥，都选 **Yes**（密钥由 Expo 保管，不要发给任何人）。
4. 等 10～20 分钟，命令行和 expo.dev 网页上会出现下载链接和二维码。手机扫码下载 APK，安装时允许“安装未知来源应用”。

免费账号每月有一定的云打包次数，内部测试足够用。

## 方法二：在当前工作区直接打包

如果你在 claude.ai 的设置里（个人付费版：设置 → Capabilities；团队版需管理员）把以下域名加入允许访问，我可以在工作区里直接编出 APK 发给你，不需要 Expo 账号：
`dl.google.com`、`maven.google.com`、`repo.maven.apache.org`、`services.gradle.org`、`plugins.gradle.org`

这种方式生成的是测试签名的安装包，只适合内部试用，不能上架。
