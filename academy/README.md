# AI 少年学院 V1.0 · 运行与验收

AI 少年学院是「星星闯关乐园」里的一个独立子应用，地址是 `/academy/`，和旧乐园共用同一个家长访问码。旧乐园的页面文件一个字节都没有改。

## 一、在自己电脑上运行（Windows PowerShell）

在项目根目录 `star-learning-park` 里依次运行：

```powershell
npm run build:academy
$env:FAMILY_ACCESS_CODE="你的访问码至少8位"
$env:SESSION_SECRET="至少32个字符的随机字符串-abcdefghijklmnop"
$env:HOST="127.0.0.1"
npm start
```

浏览器打开 `http://127.0.0.1:10000/login`，输入访问码，再打开 `http://127.0.0.1:10000/academy/`。

## 二、运行全部自动化测试

```powershell
npm test
```

应该看到：服务端 25 项全部通过（旧乐园回归测试 14 项 + 学院挂载测试 11 项），学院 43 项全部通过。

## 三、V1.0 验收步骤

| # | 验收标准 | 怎么验证 |
| --- | --- | --- |
| 1 | 旧乐园不受影响 | 打开 `/`，数学、语文、英语照常使用；`npm test` 里 `legacy` 部分全部通过（其中一项会核对旧页面文件的指纹，确认没有被改动）。 |
| 2 | 学习记录真实保存 | 在学院里新建孩子 → 学完「AI 是什么？」→ 关闭浏览器再打开 → 课程地图上第 1 课显示 ⭐ 已完成，课程详情显示已学时长。 |
| 3 | 未完成的年级如实显示 | 课程地图点「4 年级」→ 显示「即将上线」和课程清单，没有可以点进去的空课程。 |
| 4 | 家长中心数据与操作一致 | 进入家长中心（先回答乘法题）→「学习进度」里的用时、首次答对数，与刚才的操作一致。 |
| 5 | 低年级界面简单 | 用手机竖屏打开，1–2 年级首页只有一个大按钮「今天学…」、三张统计卡和「课程地图」，文字带拼音。 |
| 6 | 离线可学 | 打开过学院后，手机开飞行模式，再打开 `/academy/`，已缓存的课程仍能学习。 |
| 7 | 隐私拦截 | 新建孩子时昵称填「我叫王小明」→ 被拒绝；家长中心「安全记录」只显示次数，不显示原文。 |

## 四、本版本的边界

- 只有一年级 7 课有完整内容；二至六年级在 V2.0 上线。
- 不连接任何 AI 模型（`/api/academy/health` 返回 `aiMode: "none"`）。
- 学习记录只存在本机浏览器（IndexedDB，库名 `ai-academy`），换设备不会同步。可以在家长中心导出备份。
- 语音输入、图片上传、对外分享、陪同模式都锁定为关闭。
- 「实践任务」的完成情况由孩子和家长自己确认，家长中心里显示为「自报完成」。
- 家长确认（乘法题）只是为了防止孩子误入，不是安全措施；真正的保护是服务端的家长访问码。
- 学习时长只计算页面打开、且 1 分钟内有操作的时间。中途离开时，最后一步之后的那一小段时间不会被计入。

# V2.0 第一轮 · 教学引擎 + 二年级

## 本轮新增

- **二年级 7 课**（AI 小小训练师）：数据是什么、数据分类、图片标签、AI 如何认识动物、语音识别体验（同音字，不开麦克风）、简单条件判断、如何给 AI 下指令。每课 12 项齐全。
- **二年级项目：模拟训练水果识别 AI**：贴标签 → 训练 → 用 4 个没见过的水果测试 → 改正标签再训练。页面明确标注"模拟实验，不是真正的 AI 模型"。只有第一次训练算作孩子的贴标签成绩；作品里"测试结果"标记为模拟 AI 生成，不计入孩子的贡献。
- **智能复习**：按知识点安排复习。当天首次作答正确率 ≥ 75% 算通过，间隔依次为 1、3、7、14、30 天；没通过就第二天再复习。首页出现"今日复习：N 个知识点"。
- **复习专用题库**：一、二年级每课 2–3 道复习题，和课堂练习题不同。
- **前置知识检查**：课程详情页会提示"这节课会用到的知识点上次还不太稳"，可以先热身复习。
- **知识点图谱**（家长中心）：每个知识点的首次答对数、状态（未学 / 需要巩固 / 学习中 / 掌握）和下次复习日期。
- **课程内容校验**：自动检查题目编号唯一、每个知识点都有题可复习（创造类知识点用作品评价，除外）。

## 本轮验收步骤

| # | 验收标准 | 怎么验证 |
| --- | --- | --- |
| 1 | 二年级课程可学 | 家长中心把孩子改成 2 年级 → 首页出现"今天学：数据是什么？" |
| 2 | 模拟训练会因错误标签变差 | 学到第 7 课项目，把「青苹果」贴成「香蕉」→ 训练后正确率 3/4；改回「苹果」重新训练 → 4/4；保存后作品显示"75% 提高到 100%" |
| 3 | 答错的知识点第二天出现在复习里 | 某课练习故意第一次答错 → 第二天首页出现"今日复习" |
| 4 | 复习改变掌握度 | 完成复习后，家长中心「知识点图谱」里该知识点的下次复习日期往后推 |
| 5 | 前置提醒 | 一年级「图像识别」的题第一次答错 → 打开二年级「图片标签」详情页，出现"先热身复习" |

## 还没做（后续轮次）

- "创造迁移"等级在认知、应用等维度需要的迁移任务。

# V2.0 第二轮 · 三年级

## 本轮新增

- **三年级 9 课**（AI 小小应用师）：如何提出好问题、提示词是什么、如何优化提示词、AI 辅助语文 / 数学 / 英语学习、算法和逻辑、AI 生成内容的判断、图形化编程入门。每课 12 项齐全，每课 2 道复习专用题。
- **不调用任何 AI**：课程里出现的 AI 回答都是预先写好的示例，一律标明"示例 AI 回答"。课程校验会自动检查：没有标"示例"的 AI 回答会让测试失败。
- **年级项目：设计我的 AI 故事助手**：孩子选角色、听众、要求，自己写故事主题，生成一张提示词卡片；检查清单全部打勾才能保存。安全规则来自平台模板，作品里如实标明。按教育部要求，本项目只设计、不生成。
- **积木编程闯关**（新互动实验）："前进 / 左转 / 右转"积木，3 关迷宫，撞墙会标出出错的那一块积木。课程校验会自动确认每一关都能在积木数量限制内完成。

## 本轮验收步骤

| # | 验收标准 | 怎么验证 |
| --- | --- | --- |
| 1 | 三年级课程可学 | 家长中心把孩子改成 3 年级 → 首页出现"今天学：如何提出好问题？" |
| 2 | 积木编程能调试 | 第 9 课：拼"前进、右转、前进"运行 → 提示没到星星；拼"前进、前进、前进"运行 → 过关；撞墙时出错积木有红框 |
| 3 | 提示词卡片 | 第 3 课项目：没选够 2 条要求时不能保存；主题写"我叫王小明"会被拦截 |

# V2.0 第三轮 · 四年级

## 本轮新增

- **四年级 8 课**（AI 小小研究员）：机器学习、训练数据与测试数据、模型和预测、数据偏差、AI 为什么会犯错、AI 信息验证、图形化编程进阶、简单分类算法。每课 12 项齐全，每课 2 道复习专用题。
- **AI 训练模拟器（模拟实验，页面有标注）**
  - 考试模式：同一个模型，用学过的水果考 5/5，用没见过的水果考 3/4，让孩子判断哪个成绩可信。
  - 数据偏差模式：训练数据里的苹果全是红的，模型把青苹果、黄苹果认成梨（2/4）。只加红苹果没用，补上青苹果和黄苹果后 4/4。
- **年级项目：智能分类游戏（真正的决策树算法）**：孩子自己选问题、定分类，用 11 张动物卡片测试；每张卡片显示走过的路径，方便找出错在哪个问题。"先问会飞吗"只能答对 7 张，"先问有羽毛吗、再问用鳃呼吸吗"可以全对。答对数量由程序计算，作品里如实标明。
- **循环积木**："重复 2 次 / 重复 3 次"重复紧跟在后面的那一块积木；3 关的积木数量限制都比不用循环时少，必须用循环。课程校验会自动确认每关都能在限制内完成。

## 本轮验收步骤

| # | 验收标准 | 怎么验证 |
| --- | --- | --- |
| 1 | 四年级课程可学 | 家长中心把孩子改成 4 年级 → 首页出现"今天学：机器学习" |
| 2 | 考试模式 | 第 2 课：考试 A 显示 5/5，考试 B 显示 3/4（黄苹果被认成香蕉） |
| 3 | 数据偏差 | 第 4 课：开始是 2/4；只加"又一个红苹果"仍是 2/4；加青苹果、黄苹果后 4/4 |
| 4 | 循环 | 第 7 课第 1 关：只用"前进"放到 4 块就满了；用"重复 3 次 前进、前进、前进"过关 |
| 5 | 决策树 | 第 8 课项目：先问"会飞吗"得 7/11；改成先问"有羽毛吗"再问"用鳃呼吸吗"得 11/11；保存后作品里显示改进记录 |
